# kiransgarage

The coming-soon page for **kiransgarage.com** — a home for projects, experiments, and things in progress.

## Preview

Open `index.html` in any modern browser. The page is self-contained: HTML, CSS, JavaScript, and SVG artwork are all in one file. No dependencies or build step are required.

## Publish with Azure Static Web Apps

Create an Azure Static Web App on the Free plan, connect this GitHub repository, and choose the `main` branch. Use the Custom build preset:

| Setting | Value |
| --- | --- |
| App location | `/` |
| API location | empty |
| Output location | empty |

For this prebuilt site, the generated GitHub Actions deployment step can use:

```yaml
app_location: "/"
api_location: ""
output_location: ""
skip_app_build: true
```

Keep the deployment secret name generated by Azure. Do not commit deployment tokens.

## Custom domain

1. In GoDaddy DNS, set the `www` CNAME to the Static Web App's generated hostname, without `https://` or a trailing slash.
2. In Azure Static Web Apps, add `www.kiransgarage.com` under Custom domains using CNAME validation.
3. Once HTTPS works, configure GoDaddy to forward `kiransgarage.com` to `https://www.kiransgarage.com` using a permanent (301), unmasked redirect.
4. Verify both HTTPS addresses. Keep unrelated DNS records, especially email records, intact.

Azure issues and renews HTTPS certificates for the custom hostname. Domain registration remains at GoDaddy.

## Editing

Update the text, colors, and illustration directly in `index.html`. The garage-door interaction supports keyboard use and honors reduced-motion preferences. Commits to `main` deploy automatically once the Azure GitHub integration is configured.
